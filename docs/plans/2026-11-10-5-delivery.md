# Delivery (stage 12) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A reviewer with only Docker runs `docker compose up --build` and gets the seeded app at `http://localhost:8080`; the README explains setup, demo logins, tests with coverage, architecture, API, decisions, AI usage and limits.

**Architecture:** One `app` container: a multi-stage `Dockerfile` builds Angular and publishes the API, and the API serves the Angular files from `wwwroot` on the same origin (cookie auth and antiforgery keep working without CORS). Unknown `/api/*` paths stay API responses (401 without a session, 404 with one); every other unknown path returns `index.html` so deep links work. Data protection keys go to a Docker volume, so login sessions survive `docker compose restart`.

**Tech Stack:** .NET 10 static files and `MapFallbackToFile`, ASP.NET Core Data Protection (`PersistKeysToFileSystem`), Docker Compose, `Microsoft.Testing.Extensions.CodeCoverage` 18.11.2 (nuget.org; depends on Microsoft.Testing.Platform 2.4.0, the version xUnit v3 4.0.1 uses; lookup approved by the human on 2026-11-10), `@vitest/coverage-v8` (npm).

**Spec:** [plan.md §4 "Running it", §6 Demo criteria, §7 stage 12 and "README contents"](../plan.md), [stack.md Docker](../stack.md#docker), [requirements.md §9](../requirements.md#9-demo-and-documentation). The GenAI answer (`docs/ai/genai-exercise.md`) is **not** in this plan: the human moved it to the last plan.

## Global Constraints

- Demo URL `http://localhost:8080`, published on `127.0.0.1` only. `db` stays on `127.0.0.1:1433`.
- No secret in committed files: the SA password comes from `.env` (`MSSQL_SA_PASSWORD`), as today.
- The container runs as the image's non-root `app` user; `ASPNETCORE_ENVIRONMENT=Production` (no Scalar, exception handler on); `Database__MigrateOnStartup=true`, `Seed__DemoData=true`.
- Base images: `node:26-alpine` (matches `frontend/.nvmrc`), `mcr.microsoft.com/dotnet/sdk:10.0`, `mcr.microsoft.com/dotnet/aspnet:10.0`. Pulling them needs the human's OK (asked at plan approval).
- Never claim a command ran unless it ran; README numbers (tests, coverage) come from real runs.
- Everything in English; no explanatory comments in code; TDD for code changes.

## Review Focus

1. **Deep link refresh** (`http://localhost:8080/students/<id>` reloaded): returns the app, not 404. Test in Task 2.
2. **Unknown API path** (`/api/nope`): 401 without session, 404 with session, never `index.html`. Test in Task 2.
3. **`docker compose restart`**: the logged-in teacher stays logged in (keys persisted). Test in Task 3 + manual in Task 4.
4. **First start on an empty volume**: the app waits for SQL Server to be healthy, migrates, seeds once; a second start adds nothing. Manual in Task 4 (seed idempotency already tested in plan 2).
5. **Stale `index.html` after a rebuild**: the browser revalidates it (`Cache-Control: no-cache`), hashed JS/CSS can be cached. Test in Task 2.
